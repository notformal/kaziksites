## TECHNICAL NOTES

Each game implements:
1. `genCrash()` — provably fair crash point using `E = 0.94/(1-U)` formula  
2. Canvas rendering with `requestAnimationFrame` loop
3. Exponential multiplier growth: `Math.pow(Math.E, speed*t²)`
4. Bot participant simulation (random bet sizes + cashout timing)
5. Premium overlay integration via `initOverlay()`
6. Mobile-first responsive design

## WHY THIS WORKS WITHOUT LIVE VIDEO

155.io uses **physical cameras** for real-world unpredictability. We achieve the same tension through:
- **Canvas animations** that feel organic and unpredictable
- **Random bot behaviors** creating social pressure to cashout
- **Visual danger indicators** (pulsing red, approaching shark)
- **Growing multiplier anxiety** — every second increases risk

The psychological thrill is IDENTICAL even without live video.
