## 🎯 PIXI.js Game Engine

**Статус:** ✅ ГОТОВО
**Файл:** `platform/games/engine/pixi-game-engine.js`

### Возможности engine:
- Game loop (requestAnimationFrame)
- Bet management (validate, apply, settle)
- Balance tracking
- RTP calculation
- Provably fair (HMAC-SHA256)
- Seeded RNG (mulberry32)
- Animation system
- Responsive design
- Error handling
- Event system

### API:
```javascript
const engine = new PIXIGameEngine({
  container: element,
  width: 800,
  height: 600,
  rtpTarget: 0.96,
  seed: 'user-seed',
  provablyFair: true,
});

// Основные методы
engine.start()
engine.stop()
engine.spin(betAmount)
engine.getCashoutMultiplier()
engine.getResult()
engine.getRTP()
engine.getState()
engine.on(event, callback)
engine.destroy()
```
